# Phase 3: ファイル一覧と制限付きダウンロード

## 目的

設定済みSharePointサイト内のドキュメントライブラリとフォルダーを読み取り専用で移動し、安全側の制限を満たすファイルをMCPクライアントへ返す。

## MCPツール

### `sharepoint_list_document_libraries`

BaseTemplate 101かつ非表示ではないリストを取得し、ドキュメントライブラリのタイトル、ルートフォルダーURL、項目数を返す。

### `sharepoint_list_folder`

ResourcePath対応REST APIで、指定フォルダー直下のフォルダーとファイルを取得する。

- 絶対URLとサーバー相対URLに対応
- フォルダーとファイルをそれぞれ最大100件、既定値50件まで返却
- 応答項目のパスが設定サイト内かつ指定フォルダーの直接の子であることを再検証
- ファイルごとにサイズ、更新日時、メジャーバージョン、ダウンロード可否を返却

### `sharepoint_download_file`

ResourcePath対応REST APIの`$value`からファイルを読み取り、MCPの埋め込みバイナリresourceとして返す。

- 最大5 MiB
- PDF、Open XML Office文書、テキスト、構造化テキスト、一般的なラスター画像だけを許可
- 実行形式、スクリプト、HTML、SVG、マクロ有効Office形式、未知の形式を拒否
- ダウンロード前にSharePointメタデータのサイズを検証
- ダウンロード後に実データのサイズをメタデータと照合
- SHA-256を返し、バイナリ本体は`structuredContent`やログへ含めない

## 処理の流れ

1. MCP入力URLを正規化する。
2. HTTPSオリジンと設定サイトパスを検証する。
3. ResourcePathの`decodedUrl`引数として`#`、`%`、空白、Unicodeを安全に符号化する。
4. `BrowserContext.request`からGET要求を送る。
5. 認証Cookieや社内プロキシの差異で取得できない場合、同一サイトページ内の`fetch`へフォールバックする。
6. HTTP状態、応答形式、応答サイズ、SharePointが返したパスを検証する。
7. ファイル取得時はMCP resourceと最小限のメタデータを返す。

## セキュリティ境界

- HTTPメソッドはGETだけを使用する。
- REST要求は設定済みサイト配下の`/_api/`だけに制限する。
- OneDrive、他サイト、テナントルート、任意URLを拒否する。
- フォルダー一覧は直接の子だけを返す。
- JSON応答は最大1 MiB、バイナリ応答は最大5 MiB。
- バイナリの許可形式は拡張子の固定リストで判定する。
- SharePointメタデータと取得バイト数が一致しない場合は結果を破棄する。
- Cookie、トークン、Authorizationヘッダー、ファイル内容をログへ記録しない。
- ローカルファイルシステムへ自動保存しない。

## 制限事項

- 一覧はページング未対応で、フォルダーとファイルをそれぞれ最大100件まで返す。
- ZIPやその他のアーカイブ、音声、動画、マクロ有効Office文書は未対応。
- DOCX、XLSX、PPTX、PDFの制限付き本文抽出はPhase 4で対応する。
- リスト項目の汎用取得、書き込み、アップロード、更新、削除は未対応。
